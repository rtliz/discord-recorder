# discord-recorder

บอท Discord อัดเสียงใน voice channel และอัดหน้าจอ (เครื่องที่รันบอทบน macOS หรือจอของคนที่แชร์ผ่านเบราว์เซอร์) แล้วส่งไฟล์กลับใน Discord หรืออัปโหลดขึ้น Google Drive

## ใช้งาน

**เมื่อมีคนแชร์จอ บอททำได้ 3 แบบ** (เลือกต่อ server):

- **⚪ ปิด** ไม่ทำอะไร
- **📣 ส่งการ์ด** (ไม่กด ไม่อัด) บอทไม่เข้าห้องและไม่อัดอะไรเองเลย (ไม่มีอัดเสียงอัตโนมัติ) แค่โพสต์การ์ด 🔴 ให้ใครสักคนกดเพื่อเริ่มอัด
- **⚡ อัดอัตโนมัติ** มีคนแชร์จอก็อัดเลย (แบบเดิม): บอทเข้าห้องทันที เสียงเริ่มอัดพร้อมภาพจอ ภาพจอมาจากตัวอัดของคนแชร์ ถ้าไม่มีตัวอัด การ์ดจะมีปุ่ม 🎥 ให้คนแชร์กดอัดจอผ่านเบราว์เซอร์ (บอทที่ไม่ได้ตั้ง `PUBLIC_URL` อัดจอเครื่องที่รันบอท) ดูหัวข้อ "อัดอัตโนมัติ"

**ครั้งแรก:** ตอนเชิญบอทเข้า server บอทส่งหน้าตั้งค่าแบบง่ายมาให้ (เมนูเลือกทีละเรื่อง) เปลี่ยนทีหลังได้ที่ `/settings` หรือปุ่ม ⚙️

**เปิดแผงควบคุม:** พิมพ์ **`@Recorder`** ในแชท · คลิกขวาที่บอท → Apps → แผงควบคุม Recorder · หรือ `/panel` (ปักหมุดไว้ได้)

```
🎛️ Recorder
⚪ ยังไม่ได้อัด — เข้าห้องเสียงแล้วกด 🎙️
📣 เมื่อมีคนแชร์จอ: **ส่งการ์ด**
[🎙️ อัดเสียง] [🖥️ อัดจอ] [🌐 อัดผ่านเบราว์เซอร์]
[⚙️ ตั้งค่า] [📁 Google Drive] [🔄]
```

- แผงที่ส่งด้วย `/panel` หรือ `@Recorder` **อัปเดตสถานะเอง** เมื่อเริ่มหรือหยุดอัด
- **การอัดแต่ละครั้งมีข้อความเดียว** ข้อความนี้เปลี่ยนจาก 🔴 กำลังอัด (มีเวลาที่อัดไปแล้วนับเอง และปุ่มหยุด) → ⏫ กำลังอัปโหลด → ✅ พร้อมปุ่มเปิดไฟล์
- **สถานะของบอท** (กดที่ชื่อบอทก็เห็น) จะขึ้นว่า 🔴 กำลังอัด หรือ ⚪ พร้อมอัด
- **ชื่อบอทใน server** บอกว่าใครกำลังอัด เช่น `KAB - 🔴 กำลังอัดหน้าจอ`, `KAB - 🔴 กำลังอัดเสียง` หรือ `KAB - ⏳ เตรียมอัด` (บอทเข้าห้องแล้ว รอภาพจอ ยังไม่ได้อัด) (KAB = ชื่อในเซิร์ฟเวอร์ของคนที่กดอัด หรือเจ้าของจอที่กำลังอัดอยู่ใน session) หยุดอัดแล้วกลับเป็นชื่อเดิม บอทต้องมีสิทธิ์ **Change Nickname**
- **🖥️ อัดจอ** อัดจอของคุณเองด้วยตัวอัดบนเครื่องคุณ (ไม่ขึ้นกับตั้งค่า "อัดจอด้วย") ถ้ายังไม่ได้เปิดตัวอัด บอทตอบเฉพาะคุณพร้อมปุ่ม 📥 ติดตั้งตัวอัด และลิงก์ 🎥 ให้อัดผ่านเบราว์เซอร์ได้เลย
- **🌐 อัดผ่านเบราว์เซอร์** ส่งลิงก์ส่วนตัวให้อัดจอผ่านเบราว์เซอร์เสมอ ไม่สั่งตัวอัด
- บอทที่ไม่ได้ตั้ง `PUBLIC_URL` มีแค่ 🖥️ อัดจอ ของเครื่องที่รันบอท (ทั้งจอ หรือเฉพาะหน้าต่าง `SCREEN_WINDOW_APP`)
- ปุ่ม 🖥️ อัดจอ และ 🎥 ในแผงควบคุมเก่ายังกดได้ (= 🖥️ อัดจอ)

**ใครกดอะไรได้:**
- ทุกคนเปิดแผงควบคุมได้
- อัด/หยุดได้: ผู้ดูแล server (Manage Server) และคนที่มี role ที่เลือกไว้ในตั้งค่า (📍 ห้อง & คน → 🔑)
- **👥 ทุกคนกดอัดได้:** ผู้ดูแล server เลือกได้ที่ ⚙️ ตั้งค่า → เมนู "ใครกดอัดได้" ค่าเริ่มต้น 🔑 เฉพาะผู้ดูแล เลือก 👥 ทุกคน แล้วทุกคนในเซิร์ฟเวอร์กด 🎙️ 🖥️ 🌐 ⏹️ ได้ ส่วนการตั้งค่ายังเป็นของผู้ดูแลเท่านั้น เมนูนี้ซ่อนไว้เมื่อตั้ง `ALLOWED_USER_IDS` (รายชื่อนั้นแทนสิทธิ์ทั้งหมด)
- ข้อยกเว้น: คนที่แชร์จอกด 🔴 / 🔁 ที่เป็นชื่อของตัวเอง และ 🎥 / ⏹️ ของการอัดจอของตัวเองได้เสมอ ไม่ต้องมี role
- ตั้งค่าได้: ผู้ดูแล server
- ถ้าตั้ง `ALLOWED_USER_IDS` ไว้ รายชื่อนั้นจะใช้แทน "ผู้ดูแล server" (role ที่เลือกยังกดอัดได้)
- คนที่กดอัดไม่ได้จะเห็นข้อความ 🔒 ที่บอกให้ผู้ดูแลเปิด ⚙️ → 👥 (หรือขอ role)
- บอทต้องส่งข้อความในห้องที่กดได้ (และแนบไฟล์ได้ถ้าไม่ได้ตั้ง Drive) ไม่อย่างนั้นจะบอกให้กดจากห้องอื่น

| คำสั่ง | ทำอะไร |
|---|---|
| `/record start` / `/record stop` | อัด / หยุดอัดเสียงในห้องเสียงที่คุณอยู่ (แยกรายคน แล้วรวมเป็น `voice.mp3`) |
| `/screen start [mode]` / `/screen stop` | อัด / หยุดอัดหน้าจอของคุณ ไม่เลือก `mode` = ตัวอัดบนเครื่องคุณ (เหมือน 🖥️), `browser` = ลิงก์เบราว์เซอร์ (เหมือน 🌐) บอทที่ไม่ได้ตั้ง `PUBLIC_URL`: `screen`/`window` = จอเครื่องที่รันบอท |
| `/panel` | ส่งแผงควบคุมที่อัปเดตสถานะเอง |
| `/settings` | ตั้งค่าการอัด (หน้าแบบง่าย + 🔧 ตั้งค่าเพิ่มเติม) |
| `/agent` | ติดตั้งตัวอัดบนเครื่องของคุณ (ต้องตั้ง `PUBLIC_URL`) ดูหัวข้อ "ตัวอัด (agent)" |

โหมดหน้าต่างจะตัดเฉพาะบริเวณที่หน้าต่างอยู่ตอนเริ่มอัด ถ้าย้ายหน้าต่างหรือมีหน้าต่างอื่นทับระหว่างอัด จะติดมาด้วย
หน้าต่างต้องอยู่บนจอหลัก และไม่ถูกย่อ

### การ์ดเมื่อมีคนแชร์จอ (กด 🔴 ถึงจะอัด)

`/settings` (หรือ ⚙️) เปิด **หน้าตั้งค่าแบบง่าย**: ข้อความเดียว มีเมนูเลือกทีละเรื่อง ตัวเลือกขึ้นต้นด้วยชื่อเรื่องนั้น จึงเห็นค่าที่ใช้อยู่ในเมนูเลย เลือกแล้วบันทึกทันที เก็บแยกต่อ server ใน `data/settings.json`

| เมนู | ตัวเลือก |
|---|---|
| เมื่อมีคนแชร์จอ | ⚡ อัดอัตโนมัติ (บอทเข้าห้องอัดเลย) / 📣 ส่งการ์ดให้กดอัด / ⚪ ไม่ทำอะไร |
| อัดจอด้วย (ต้องตั้ง `PUBLIC_URL`) | 🖥️ ตัวอัดในเครื่อง (ต้องติดตั้งตัวอัด; เครื่องที่ยังไม่ได้ติดตั้งได้ลิงก์เบราว์เซอร์แทน) / 🌐 เบราว์เซอร์ (ลิงก์ทุกครั้ง ไม่สั่งตัวอัด) ใช้กับการเริ่มอัดจากการแชร์ (🔴, อัตโนมัติ, 🔁, 🔴 ต่อ) |
| กรอบอัด (ต้องตั้ง `PUBLIC_URL`, แสดงเฉพาะโหมดตัวอัด) | 🖼️ ทั้งหน้าจอ / 💬 แค่หน้าต่าง Discord (ดูหัวข้อ "กรอบอัดหน้าจอ") ในโหมดเบราว์เซอร์เมนูนี้ถูกซ่อน และลิงก์หน้าอัดจอไม่ใช้ค่านี้ |
| ใครกดอัดได้ | 🔑 เฉพาะผู้ดูแล (และ role ที่ตั้งไว้) / 👥 ทุกคน (ซ่อนเมื่อตั้ง `ALLOWED_USER_IDS`) |

กด **🔧 ตั้งค่าเพิ่มเติม** เพื่อดูตัวกรอง (ใช้ทั้งกับการ์ดและอัดอัตโนมัติ) กด **◀️ กลับ** เพื่อกลับหน้าแบบง่าย

| แท็บ | ตั้งค่าอะไร |
|---|---|
| ⏳ เงื่อนไข | คนในห้องกี่คนขึ้นไป (1–5), ต้องแชร์ต่อเนื่องกี่วินาที (กันแชร์ผิด), ความยาวสูงสุดของทุกการอัด (กันลืมปิด) บอทที่ไม่ได้ตั้ง `PUBLIC_URL` เลือกทั้งจอ/เฉพาะหน้าต่างของเครื่องที่รันบอทที่นี่ |
| 📍 ห้อง & คน | ห้องเสียงที่เฝ้า, role ที่แชร์จอแล้วขึ้นการ์ด, ห้องที่แจ้งผล (ว่าง = แชทของห้องเสียง), 🔑 role ที่กดอัด/หยุดได้ |
| 🕘 เวลา | วันและช่วงชั่วโมงที่ใช้ (ตาม `TIMEZONE`, ข้ามเที่ยงคืนได้ เช่น 22:00–06:00 โดยวันนับตามเวลาปัจจุบัน: ศุกร์ 22–06 จะไม่รวมเช้าวันเสาร์ถ้าไม่ได้เลือกวันเสาร์) |

ปุ่มตั้งค่าในข้อความเก่า (⚪/📣/⚡, 👥) ยังกดได้

ค่าเดิมที่เคยบันทึกไว้ถูกแปลงตอนอ่านโดยไม่แก้ไฟล์: `mode: screen/window` → ตัวอัดในเครื่อง (เมื่อตั้ง `PUBLIC_URL`), `autoScreen: true` → อัดอัตโนมัติ, `autoVoice: members` → ส่งการ์ด, `shareCards: true/false` → ส่งการ์ด/ปิด (ตัวเลือกอัดเสียงอัตโนมัติและพรีเซ็ตเลิกใช้แล้ว)

การทำงาน:

- มีคนแชร์จอในห้องที่เฝ้า → บอทโพสต์ **การ์ดเดียวต่อห้อง** `🖥️ @B กำลังแชร์จอใน Meeting · กด 🔴 เพื่ออัด` พร้อม ping คนแชร์ ยังไม่เข้าห้อง ยังไม่อัดอะไร ถ้ามีหลายคนแชร์จะมีปุ่ม 🔴 ต่อคน (ไม่เกิน 3) เลิกแชร์หมดการ์ดจะถูกลบ
- กด 🔴 → **เริ่ม session และเตรียมอัดทันที**: บอทเข้าห้องเลย แต่**ยังไม่อัดอะไร** การ์ดขึ้น `⏳ เตรียมอัดในห้อง …` (ชื่อบอท `… - ⏳ เตรียมอัด`) พร้อมกันนั้นสั่งตัวอัดบนเครื่องคนแชร์ (อัดจอด้วย = ตัวอัด และเขามีตัวอัดออนไลน์) ไม่มีการถามบนเครื่อง ถ้าไม่มีตัวอัด หรือสั่งไม่สำเร็จ (เครื่องไม่ว่าง ไม่ตอบ ffmpeg ฯลฯ) การ์ดมีปุ่ม 🎥 ลิงก์ให้คนแชร์อัดจอผ่านเบราว์เซอร์ และหมายเหตุบอกสาเหตุ (บอทที่ไม่ได้ตั้ง `PUBLIC_URL` อัดจอเครื่องที่รันบอทแทน)
- **เสียงในห้องเริ่มอัดพร้อมภาพจอ** (ตัวอัดเริ่ม หรือเปิดลิงก์แล้วแชร์) ไม่มีช่องว่างเพราะบอทอยู่ในห้องรอแล้ว ช่วงเตรียมอัดไม่มีเวลาหมด รอได้ตราบที่คนแชร์ยังแชร์อยู่ ถ้าจบก่อนมีภาพ (เลิกแชร์ ออกจากห้อง กด ✖️/⏹️ ทุกคนออก ครบความยาวสูงสุด) การ์ดขึ้น `⚪ ไม่ได้อัด — ไม่มีภาพจอ` ไม่มีไฟล์ ไม่อัปโหลด บอทออกจากห้อง **อัดเสียงอย่างเดียวได้จาก 🎙️ อัดเสียง เท่านั้น**
- ถ้าบอทเข้าห้องไม่ได้ ภาพจากตัวอัดยังอัดต่อพร้อมหมายเหตุ ถ้าไม่มีภาพเลยจะยกเลิก
- **หนึ่ง session ต่อหนึ่ง server** (บอทอยู่ได้ห้องเดียว) กด 🔴 ในอีกห้องจะได้ข้อความว่ากำลังอัดห้องไหนอยู่
- ระหว่างอัดมีคนอื่นแชร์เพิ่ม → การ์ดมีปุ่ม **🔁** เปลี่ยนไปอัดจอเขา (บอทเริ่มอัดคนใหม่ได้ก่อนแล้วค่อยหยุดคนเก่า เสียงไม่ขาด)
- คนที่อัดอยู่หยุดแชร์ แต่ยังมีคนแชร์อยู่ → **รอ 2 นาที** เสียงยังอัดต่อ (เพราะมีภาพแล้ว) การ์ดมีปุ่ม **🔴 อัดจอ ... ต่อ** กดทันก็ต่อ ไม่มีใครกดก็จบเอง ถ้าไม่มีใครแชร์เหลือเลย จบทันที
- จบเมื่อ: กด ⏹️, ไม่มีใครแชร์เหลือ, ทุกคนออกจากห้อง, ครบความยาวสูงสุด, หรือรอครบ 2 นาที
- ผลลัพธ์คือ **ไฟล์เดียว `meeting.mp4`** มีภาพของทุกคนที่อัดและเสียงทั้งห้องต่อเนื่อง (ช่วงที่ไม่มีภาพเป็นจอดำ) ถ้ามีคนแชร์คนเดียวตลอดจะไม่ encode ภาพใหม่ แต่ถ้ามีหลายช่วงบอทต้อง encode ใหม่ ใช้ CPU ราว 10–25 นาทีต่อชั่วโมงของการประชุม และทำทีละงาน ถ้ารวมไม่สำเร็จจะส่งแยกไฟล์พร้อมหมายเหตุ
- ถ้าคนแชร์กดหยุดที่ตัวอัด/หน้าเว็บ หรือเริ่มไม่สำเร็จจนยกเลิก บอทจะไม่ขึ้นการ์ดซ้ำจนกว่าเขาจะเลิกแชร์แล้วแชร์ใหม่ (จบ session ก็เช่นกัน)
- ตั้งค่า (ปิดการ์ด เวลา ห้อง) มีผลกับการ์ดและการเริ่มอัดอัตโนมัติเท่านั้น session ที่เริ่มแล้วไม่ถูกตัดกลางคัน
- ความยาวสูงสุดใช้ค่า ณ ตอนเริ่มอัด เปลี่ยนค่าระหว่างอัดจะมีผลกับการอัดครั้งถัดไป
- 🎙️ อัดเสียง กดเองยังเหมือนเดิม ได้ไฟล์ `voice.mp3`

### อัดอัตโนมัติ

ตั้ง ⚡ อัดอัตโนมัติ แล้ว ตัวกรองทั้งหมดใช้เหมือนการ์ด (ห้อง, role, เวลา, จำนวนคนในห้อง, แชร์ต่อเนื่องกี่วินาที)

- มีคนแชร์จอ → **บอทเริ่ม session เองทันที** เหมือนเจ้าตัวกด 🔴 เอง: เข้าห้องเตรียมอัดเลย (เสียงเริ่มอัดพร้อมภาพ) และ
  - ถ้า **ตัวอัดของเขาออนไลน์** (อัดจอด้วย = ตัวอัด) สั่งตัวอัดอัดจอเขา ไม่มีการถามบนเครื่อง
  - ถ้า **ไม่มีตัวอัด** การ์ดขึ้น `⏳ เตรียมอัดในห้อง … · @คนแชร์ กด 🎥 เพื่อเริ่มอัด` พร้อมปุ่มลิงก์ (สร้างครั้งเดียว ใช้ได้ตลอดการอัดหรือ 24 ชม. ไม่หมดใน 5 นาที) กดแล้วภาพเข้าไฟล์เดียวกัน ถ้าตัวอัดของเขาออนไลน์ระหว่างที่ยังไม่ได้เปิดลิงก์ บอทสลับไปอัดด้วยตัวอัดให้ (ครั้งเดียว)
  - บอทที่ไม่ได้ตั้ง `PUBLIC_URL`: อัดจอเครื่องที่รันบอท
  - การ์ดบอกว่า `⚡ อัดอัตโนมัติ` ชื่อบอทเป็น `<ชื่อคนแชร์> - 🔴 อัดจออัตโนมัติ`
- ตัวอัดเริ่มไม่สำเร็จ → ยังเตรียมอัดอยู่ ได้ลิงก์แทน (ไม่เปิดลิงก์ก็ไม่ได้อัดอะไร) และจะไม่สั่งตัวอัดของคนนั้นอัตโนมัติอีกจนกว่าเขาจะแชร์ใหม่ (ไม่วนลองซ้ำ)
- กด ⏹️ หรือกด `s` ที่ตัวอัด → หยุด และจะไม่อัดคนนั้นอีกจนกว่าเขาจะเลิกแชร์แล้วแชร์ใหม่
- ระหว่างอัด A แล้ว B แชร์ซ้อน → **ไม่สลับเอง** ยังมีปุ่ม 🔁 ให้กด เมื่อ A หยุดแชร์ (หรือตัวอัดของ A หลุด หรือ A กด `s`) บอทอัดจอ B ต่อทันทีใน session และไฟล์เดิม (ตัวอัดของ B ถ้ามี ไม่มีก็ลิงก์ของ B) ไม่ต้องรอ 2 นาที เครื่องที่หลุดไปจะไม่ถูกเริ่มซ้ำอัตโนมัติ ต้องกด 🔴 ต่อ
- ยังเป็น 1 session ต่อ 1 server: อีกห้องที่มีคนแชร์ระหว่างนั้นได้การ์ด 🔴 ไม่เริ่มเอง (พอ session แรกจบ ถ้าคนนั้นยังแชร์อยู่และมีตัวอัด บอทจะเริ่มให้)

(Discord ไม่ให้บอทรับภาพ screen share ของคนอื่น จึงอัดได้เฉพาะจอเครื่องที่รันบอท หรือจอที่คนแชร์อัดเองผ่านตัวอัดหรือเบราว์เซอร์ ดูหัวข้อ "ตัวอัด (agent)" และ "อัดจอผ่านเบราว์เซอร์")

## ตัวอัด (agent)

ตัวอัดคือโปรแกรมเล็กๆ บนเครื่องของคุณเอง ใช้อัดจอแทนเบราว์เซอร์ (ไม่ต้องเปิดแท็บค้าง เลือกจอไม่ต้องกดซ้ำ) ต้องตั้ง `PUBLIC_URL` ไม่มีโทเคน Discord อยู่ในตัวอัด และ **ไม่เคยอัดเองโดยไม่ถูกสั่ง** มันอัดเฉพาะตอนมีคนกด 🔴 ที่การ์ดของคุณ, คุณกด 🖥️ อัดจอ เอง หรือ server ตั้ง ⚡ อัดอัตโนมัติ แล้วคุณแชร์จอใน Discord ตอนติดตั้งครั้งแรกสคริปต์ถามครั้งเดียวว่า **ให้บอทอัดจอเครื่องนี้ไหม? (y/N)** ตอบ y ถึงจะติดตั้ง หลังจากนั้นบอทอัดได้โดยไม่ถามอีก (กด `s` หยุดได้ทุกเมื่อ) ตัวอัดอัดทั้งจอที่เลือกไว้เป็นค่าเริ่มต้น ถ้าตั้ง "กรอบอัด" เป็นแค่หน้าต่าง Discord ตัวอัดบน Windows/macOS จะอัดเฉพาะหน้าต่างนั้น (Linux หรือหาหน้าต่างไม่เจอ อัดทั้งจอพร้อมหมายเหตุ ตัวอัดรุ่นเก่าอัดทั้งจอเสมอ ดูหัวข้อ "กรอบอัดหน้าจอ") ปิดของส่วนตัวก่อนแชร์

**ติดตั้ง (ครั้งเดียวต่อเครื่อง):** พิมพ์ `/agent` หรือกด **📥 ติดตั้งตัวอัด** (มีบนแผงควบคุม การ์ดแชร์จอ และลิงก์ส่วนตัว) บอทตอบเฉพาะคุณเป็นคำสั่งบรรทัดเดียว มีโทเคนใช้ครั้งเดียว หมดอายุใน 10 นาที (มือถือติดตั้งไม่ได้)

```
# macOS / Linux (วางใน Terminal)
curl -fsSL https://recorder.example.com/agent/install.sh | DRA_TOKEN=<token> sh

# Windows (วางใน PowerShell)
$env:DRA_TOKEN='<token>'; irm https://recorder.example.com/agent/install.ps1 | iex
```

- ก่อนโหลดอะไร สคริปต์ถาม `ให้บอทอัดจอเครื่องนี้ไหม? (y/N)` ตอบอย่างอื่นหรือรันโดยไม่มีหน้าต่าง Terminal/PowerShell ให้ตอบ = `ยกเลิกการติดตั้ง ไม่ได้ติดตั้งอะไร` (ไม่โหลด ไม่จับคู่ โทเคนยังใช้ได้) รันซ้ำเพื่ออัปเดตจะไม่ถามอีก เครื่องที่ติดตั้งไว้ก่อนหน้านี้ถือว่าตอบแล้ว
- สคริปต์โหลด Node และ ffmpeg ของตัวเองลง `~/.discord-recorder-agent` (ไม่แตะของที่ติดตั้งในเครื่อง) ตรวจ SHA-256 ที่ pin ไว้ก่อนใช้ แล้วจับคู่เครื่องกับบัญชี Discord ของคุณ การตรวจ SHA-256 กันไฟล์ที่ถูกแก้ไขหรือเสียระหว่างโหลด และกันต้นทางถูกยึด แต่คุณต้องเชื่อใจเซิร์ฟเวอร์บอทเอง เพราะค่า pin และ manifest มาจากเซิร์ฟเวอร์นั้น
- **macOS:** จะถามสิทธิ์ Screen Recording ให้ **Terminal** (หรือ iTerm ที่คุณใช้) เปิดที่ System Settings → Privacy & Security → Screen & System Audio Recording แล้วปิดเปิด Terminal ใหม่
- สคริปต์ถามว่าจะให้ตัวอัดเปิดเองทุกครั้งที่เข้าเครื่องไหม (ไม่บังคับ macOS เปิด Terminal ให้ ส่วน Windows ใส่ใน startup)
- รันคำสั่งเดิมซ้ำเพื่ออัปเดตได้ (ไม่ต้องจับคู่ใหม่)
- เปิดบนหลายเครื่อง: **เครื่องที่เชื่อมต่อล่าสุดใช้งาน** เครื่องเก่าจะขึ้น `⚠️ เครื่องอื่นของคุณเชื่อมต่อแทนแล้ว กด r เพื่อใช้เครื่องนี้`

**สิ่งที่เห็นบนเครื่อง:**

- `⚪ พร้อม — เชื่อมกับ <server> ในชื่อ <user>` ตอนว่าง และ `🔴 กำลังอัดจอ 00:12:34 · กด s เพื่อหยุด` ตอนอัด (ขึ้นที่ชื่อหน้าต่างด้วย macOS มีแจ้งเตือนตอนเริ่ม/หยุด)
- กด `s` หยุดอัดเอง (ถือเป็นการหยุดของคนแชร์ ไม่ขึ้นการ์ดซ้ำจนกว่าจะเลิกแชร์) `d` เปลี่ยนจอ `r` ใช้เครื่องนี้แทนเครื่องอื่น `q` ออก ตัวอัดไม่ถามอะไรตอนอัด (ค่าที่เคยตั้งให้ถามไว้ถูกล้างตอนอัปเดต) **ต้องรันคำสั่งติดตั้งจาก `/agent` ใหม่เพื่ออัปเดต** ตัวอัดรุ่นเก่ายังถามบนเครื่องอยู่และไม่รู้จักกรอบอัด
- ตัวอัดเก็บสำเนาไฟล์ไว้ที่ `~/.discord-recorder-agent/recordings/` และลบเองเมื่อบอทรับครบ ถ้าส่งไม่สำเร็จจะเก็บไว้และแจ้ง path
- ยังไม่อัดเสียงของเครื่อง (เสียงพูดมาจากการอัดห้องเสียงของบอท)

**เปิด / ลบ / อัปเดตทีหลัง:** ตอนติดตั้งเสร็จ สคริปต์พิมพ์คำสั่งเหล่านี้ไว้ให้ (📌 คำสั่งที่ใช้ภายหลัง)
- เปิดตัวอัด: `~/.discord-recorder-agent/start.command` (Windows: `%USERPROFILE%\.discord-recorder-agent\start.cmd` ดับเบิลคลิกได้)
- ลบตัวอัด: `~/.discord-recorder-agent/uninstall.command` (Windows: `uninstall.cmd` ในโฟลเดอร์เดียวกัน) ถามก่อน (y/N) แล้วปิดการเปิดอัตโนมัติและลบทั้งโฟลเดอร์ รวมไฟล์สำรอง ปิดตัวอัด (q) ก่อน แล้วกด 🗑️ ยกเลิกเครื่องใน `/agent`
- อัปเดต: ขอคำสั่งใหม่จาก `/agent` แล้ววางอีกครั้ง

**ยกเลิกเครื่อง:** `/agent` แสดงเครื่องที่จับคู่แล้วพร้อมปุ่ม 🗑️ ยกเลิกเครื่องนั้น (หรือยกเลิกทั้งหมด) ตัวอัดเครื่องนั้นจะลบ credential ของตัวเองเมื่อรู้ตัว

ผู้ดูแล server (Manage Server หรืออยู่ใน `ALLOWED_USER_IDS`) จะเห็นส่วน **ตัวอัดใน server นี้** ต่อท้ายใน `/agent` ด้วย: ตัวอัดของสมาชิกคนอื่นที่จับคู่จาก server นี้ (เครื่องที่จับคู่ก่อนมีฟีเจอร์นี้นับเฉพาะเจ้าของที่ยังอยู่ใน server) พร้อมปุ่ม 🗑️ ลบทีละเครื่อง แสดงเครื่องล่าสุดก่อน (`แสดง N จาก M` ถ้าไม่พอที่) บอทเช็กสิทธิ์ใหม่ทุกครั้งที่กด และบันทึก log ว่าใครลบตัวอัดของใคร ถ้าเครื่องนั้นกำลังอัดอยู่ ตัวอัดจะหยุด ส่งส่วนที่อัดได้แล้วขึ้นบอท และวิดีโอส่วนนั้นยังอยู่ในผลลัพธ์

**🖥️ อัดจอ:** ถ้าเครื่องของคุณมีตัวอัดออนไลน์ บอทเข้าห้องและโพสต์การ์ด ⏳ เตรียมอัด ทันที แล้วสั่งตัวอัดอัดจอ (เสียงเริ่มอัดพร้อมภาพ) ต่อเนื่องจนกด ⏹️ ออกจากห้อง ครบความยาวสูงสุด หรือตัวอัดหลุด (ได้ไฟล์เท่าที่อัดพร้อมหมายเหตุ) ถ้าสั่งตัวอัดไม่สำเร็จ ข้อความที่เห็นคนเดียวจะมีลิงก์เบราว์เซอร์ให้อัดจอเข้าไฟล์เดียวกัน (ไม่เปิดลิงก์ก็ไม่ได้อัดอะไร) ถ้าไม่มีตัวอัดได้ลิงก์ส่วนตัวพร้อมปุ่ม 📥 ติดตั้งตัวอัด

### กรอบอัดหน้าจอ

ตั้งที่ ⚙️ → เมนู "กรอบอัด": **🖼️ ทั้งหน้าจอ** (ค่าเริ่มต้น) หรือ **💬 แค่หน้าต่าง Discord**
- **Windows:** ตัวอัดหาหน้าต่าง Discord ตอนเริ่มอัด (ชื่อหน้าต่างเปลี่ยนตามห้อง) แล้วอัดเฉพาะหน้าต่างนั้น
- **macOS:** อัดเฉพาะบริเวณที่หน้าต่าง Discord อยู่ตอนเริ่มอัด ถ้าย้ายหรือย่อขยายหน้าต่างระหว่างอัด กรอบจะไม่ตาม ไม่ต้องให้สิทธิ์เพิ่ม (ใช้สิทธิ์ Screen Recording ของ Terminal เดิม)
- **Linux** หรือหาหน้าต่าง Discord ไม่เจอ (ย่อไว้ อยู่จออื่น): อัดทั้งจอแทน และการ์ดมีหมายเหตุ `หาหน้าต่าง Discord ไม่เจอ อัดทั้งจอแทน`
- **เบราว์เซอร์:** บังคับหน้าต่างไม่ได้ หน้าอัดจอจะบอกให้เลือกหน้าต่าง Discord และเปิดแท็บเลือกหน้าต่างไว้ก่อน (เฉพาะลิงก์ที่ใช้แทนตัวอัดในโหมดตัวอัด ในโหมดเบราว์เซอร์ลิงก์ไม่ใช้ค่านี้)
- ตัวอัดรุ่นเก่าไม่รู้จักค่านี้และอัดทั้งจอ บอทไม่รู้ว่าเป็นรุ่นเก่า ให้รันคำสั่งติดตั้งจาก `/agent` ใหม่

**ผู้พัฒนา:** `npm run agent -- --server https://... --code <รหัส 6 หลักจาก /agent>` (ครั้งแรก เก็บค่าใน `~/.discord-recorder-agent/config.json`) แล้วรัน `npm run agent` ตัวอัดที่ติดตั้งด้วยสคริปต์ใช้เฉพาะ ffmpeg ที่มากับมัน (`<home>/bin`) ถ้าไม่ตั้ง `DRA_HOME` ใช้ `ffmpeg` บน PATH ได้ แต่ถ้าตั้ง `DRA_HOME` เอง ต้องวาง ffmpeg ไว้ใน `<home>/bin` หรือใส่ `DRA_FFMPEG` ปิดการจับคู่ด้วยรหัสได้ด้วย `AGENT_CODE_PAIRING=false`

**ผู้ดูแล:** `npm run build:agent` โหลดไฟล์ Node/ffmpeg ที่ pin ไว้ใน `src/agent/pins.json` ใหม่ คำนวณ SHA-256 แล้วพิมพ์ส่วนที่เปลี่ยน ให้ตรวจใน git ก่อน commit (`--dry` ไม่เขียนไฟล์, `--bump node=<รุ่น>` / `--bump ffmpeg=<รุ่น>` เปลี่ยนรุ่น) ไฟล์ติดตั้งและ JS ของตัวอัดอยู่ใน `src/agent/` และถูกเสิร์ฟจากบอทเอง ไม่ต้อง build ใหม่เมื่อแก้ JS

### เมื่อบอทรีสตาร์ท หรือหลุดจากห้องเสียง

- **บอทรีสตาร์ท** (ดับ, deploy ใหม่, Mac รีบูต) การอัดที่กำลังทำอยู่จะหยุดทันทีและไม่ได้ส่งผล ไฟล์ที่อัดไว้แล้วอาจยังอยู่ในโฟลเดอร์ `recordings/` แต่บอทไม่ส่งให้อัตโนมัติ การ์ดที่ค้างจะเปลี่ยนเป็น `⚠️ บอทรีสตาร์ทระหว่างอัด การอัดนี้หยุดแล้ว` และชื่อบอทในเซิร์ฟเวอร์กลับเป็นชื่อเดิม
- **บอทถูกเตะออกจากห้องเสียง** หรือหลุดการเชื่อมต่อเกิน 5 วินาที การอัดเสียงในห้องนั้นจะจบ การ์ดขึ้น `⚠️ บอทหลุดจากห้องเสียง` และส่งเสียงที่อัดถึงตอนนั้น ถ้าเป็นเสียงที่คู่กับการอัดจอ วิดีโอจะอัดต่อ และผลจะบอกว่าเสียงมีถึงตอนนั้น (ถ้ายังเตรียมอัดอยู่ ไม่มีภาพ จะจบเป็น ⚪ ไม่ได้อัด)

## ติดตั้ง

ต้องมี Node.js และ ffmpeg (`brew install ffmpeg`)

```
npm install
cp .env.example .env   # แล้วกรอกค่า
npm start
```

- `DISCORD_TOKEN`, `CLIENT_ID`: จาก Discord Developer Portal (คำสั่งลงทะเบียนแบบ global ใช้ได้ทุก server ที่เชิญบอท)
- `AUTO_SCREEN_USER_IDS`: (ไม่บังคับ) user ID ที่การแชร์จอจะขึ้นการ์ด 🔴
- `SHARE_CARDS`, `AUTO_SCREEN_MIN_MEMBERS`, `SCREEN_MODE`, `AUTO_SCREEN_CHANNEL_IDS`: ค่าเริ่มต้นของ server ที่ยังไม่ได้ตั้งค่าผ่าน `/settings`
- `TIMEZONE`: timezone ของช่วงเวลาส่งการ์ด (ค่าเริ่มต้น `Asia/Bangkok`)
- `ALLOWED_GUILD_IDS`: server ที่ใช้บอทได้ คั่นด้วย comma บอทจะออกจาก server อื่นเองทันทีที่ถูกเชิญ (แนะนำให้ตั้ง)
- `LEAVE_UNLISTED`: `true` = ตอนบอทเริ่ม ให้ออกจาก server ที่บอทอยู่แล้วแต่ไม่อยู่ใน `ALLOWED_GUILD_IDS` (ค่าเริ่มต้นแค่ไม่สนใจ server นั้น กันพิมพ์ id ผิดแล้วบอทออกจากทุก server)
- `CAPTURE_AREA`: กรอบอัดเริ่มต้น `screen` (ทั้งจอ ค่าเริ่มต้น) หรือ `discord` (แค่หน้าต่าง Discord) ของ server ที่ยังไม่ได้ตั้งค่า
- `SHARE_CARDS`: ค่าเริ่มต้นเมื่อมีคนแชร์จอ ของ server ที่ยังไม่ได้ตั้งค่า: `true` (หรือ `card`) = ส่งการ์ด, `auto` = อัดอัตโนมัติ, `false` = ปิด (ค่าเริ่มต้น) ถ้าไม่ได้ตั้ง จะดูชื่อเดิม `AUTO_SCREEN`: `true` = อัดอัตโนมัติ
- `AGENTS_FILE` (ค่าเริ่มต้น `data/agents.json`), `AGENT_CODE_PAIRING`, `HTTP_MAX_CONNECTIONS` (ค่าเริ่มต้น 512): ดูหัวข้อ "ตัวอัด (agent)" และ "อัดจอผ่านเบราว์เซอร์"
- `SCREEN_MODE`: มี `PUBLIC_URL`: `agent` (ค่าเริ่มต้น; `screen`/`window` ก็อ่านเป็น `agent`) | `browser` · ไม่มี `PUBLIC_URL`: `screen` | `window` (เฉพาะ Mac)
- `PUBLIC_URL`, `HTTP_PORT`, `CAPTURE_MAX_MB`, `CAPTURE_TOTAL_MB`, `DELETE_AFTER_UPLOAD`: ดูหัวข้อ "อัดจอผ่านเบราว์เซอร์"
- `SCREEN_DEVICE`: index ของจอจาก `ffmpeg -f avfoundation -list_devices true -i ""`
- ครั้งแรกต้องเปิด Screen Recording ให้ Terminal/Cursor ที่ System Settings → Privacy & Security

## อัปโหลดขึ้น Google Drive

ถ้าตั้งค่าครบ บอทจะส่งลิงก์ Drive แทนการแนบไฟล์ ถ้าไม่ตั้ง จะแนบไฟล์ใน Discord (ไม่เกิน 10MB)

1. ที่ [Google Cloud Console](https://console.cloud.google.com/) สร้าง project แล้วเปิด **Google Drive API**
2. OAuth consent screen: เลือก External แล้วเพิ่มอีเมลของคุณเป็น Test user
3. Credentials → Create OAuth client ID ชนิด **Web application** ใส่ Authorized redirect URI เป็น `http://localhost:53682`
4. ใส่ `GOOGLE_CLIENT_ID` และ `GOOGLE_CLIENT_SECRET` ใน `.env`
5. ใส่ `DRIVE_FOLDER_ID` เป็นรหัสท้าย URL ของโฟลเดอร์ (`drive.google.com/drive/folders/<รหัสนี้>`)
6. รัน `npm run drive-auth` เปิดลิงก์ที่แสดงแล้วอนุญาต จะได้ `GOOGLE_REFRESH_TOKEN` ให้ใส่ใน `.env`
7. รัน `npm start` ใหม่

บัญชีที่อนุญาตต้องมีสิทธิ์แก้ไขโฟลเดอร์นั้น ถ้า OAuth app ยังเป็นโหมด Testing refresh token จะหมดอายุทุก 7 วัน
ให้รัน `drive-auth` ใหม่ หรือ Publish app เพื่อไม่ให้หมดอายุ

ไฟล์จะแยกโฟลเดอร์ตามเซิร์ฟเวอร์ (บอทสร้างให้เองใต้ `DRIVE_FOLDER_ID` ถ้ายังไม่มี) และตั้งชื่อตามเวลาที่เริ่มอัด (ตาม `TIMEZONE`) กับชื่อห้องเสียง เช่น

```
<DRIVE_FOLDER_ID>/
  ชื่อเซิร์ฟเวอร์/
    2026-11-12 11.06 Meeting.mp4          วิดีโอ
    2026-11-12 11.06 Meeting (เสียง).mp3  ไฟล์เสียง
    2026-11-12 11.06 Meeting (วิดีโอ 2).mp4  กรณีส่งแยกหลายช่วง
```

ถ้าสร้างโฟลเดอร์ไม่ได้ บอทจะอัปไฟล์ไว้ที่โฟลเดอร์หลักแทน (ไฟล์ไม่หาย)

ถ้าอัปขึ้น Drive ไม่สำเร็จ บอทจะแนบไฟล์ใน Discord ให้แทน (ถ้าไม่เกิน 10MB ไฟล์ใหญ่กว่านั้นจะบอกที่อยู่ไฟล์ในเครื่อง) ถ้า Drive ตอบว่าการเชื่อมต่อหมดอายุ (`invalid_grant`) ข้อความผลจะบอกให้ผู้ดูแลบอทรัน `npm run drive-auth` ใหม่ แล้วอัปเดต `GOOGLE_REFRESH_TOKEN` (ใน `.env` หรือ secret) และเริ่มบอทใหม่

## อัดจอผ่านเบราว์เซอร์ (ใช้บน k8s ได้)

**เลือกวิธีอัดจอ:** `/settings` → 🔧 ปรับละเอียด → 🖥️ การอัด → **อัดแบบ**
- **จอของคนกด/คนแชร์ ผ่านเบราว์เซอร์** — ภาพมาจากเบราว์เซอร์ของคนที่กด (ต้องตั้ง `PUBLIC_URL`) ใช้บน k8s ได้
- **ทั้งจอ / หน้าต่าง บนเครื่องที่รันบอท** — แบบเดิม ffmpeg อัดจอ Mac ที่รันบอท (ต้อง `SCREEN_ENABLED=true` ใช้ได้เฉพาะ macOS)
- ทั้งสองแบบ บอทเข้าห้องเสียงของคนกด/คนแชร์ไปอัดเสียงคู่กัน แล้วออกเมื่อหยุดอัด
- ถ้าเปิดไว้แบบเดียว ตัวเลือกนี้จะไม่แสดง

Discord ไม่ให้บอทรับภาพ screen share ของใคร โหมดนี้จึงให้ **คนที่แชร์จอเป็นคนอัดเอง** ในเบราว์เซอร์ของเขา แล้วส่งวิดีโอมาให้บอท
ไม่ต้องมีจอบนเครื่องที่รันบอท จึงใช้ได้บน k8s (`SCREEN_ENABLED=false`) และกับหลาย server พร้อมกัน

**ขั้นตอนของผู้ใช้:**

1. **อัดจอเอง:** กด 🌐 อัดผ่านเบราว์เซอร์ ที่แผงควบคุม / `/screen start mode:browser` (หรือ 🖥️ อัดจอ เมื่อยังไม่มีตัวอัด) (ต้องอยู่ในห้องเสียง) บอทตอบลิงก์ให้เห็นคนเดียว **ยังไม่โพสต์อะไรในห้อง และบอทยังไม่เข้าห้อง** จนกว่าหน้าจะเริ่มอัดจริง
   **จากการ์ด:** มีคนแชร์จอ → บอทโพสต์การ์ด 🔴 พร้อม ping คนแชร์ (โหมดส่งการ์ด) เมื่อมีคนกด 🔴 หรือเริ่มเองในโหมดอัดอัตโนมัติ บอทเข้าห้องเตรียมอัดทันที (เสียงเริ่มอัดเมื่อภาพขึ้น) และถ้าไม่ใช้ตัวอัด การ์ดจะมีปุ่มลิงก์ให้คนแชร์ (ไม่มีเวลาหมดอายุ)
2. **คนแชร์กดลิงก์:**
   - จากการ์ด: กดปุ่มลิงก์ **🎥 เริ่มอัดจอของฉัน** ที่อยู่บนการ์ดของ session (หลังมีภาพแล้วจะเป็น **🎥 อัดจอของฉันด้วย**)
   - กดเอง: กด **🌐 อัดผ่านเบราว์เซอร์** บอทตอบเฉพาะคุณ (ephemeral) เป็นปุ่มลิงก์ **🎥 เปิดหน้าอัดจอ**
3. หน้าเว็บเปิดในเบราว์เซอร์บนคอมพิวเตอร์ และเปิดตัวเลือกจอให้เอง (ถ้าเบราว์เซอร์ไม่เปิดให้ ให้กด **▶️ เริ่มอัดจอ**) เลือกจอ/หน้าต่างเดียวกับที่แชร์ใน Discord (ติ๊กแชร์เสียงของแท็บ/ระบบได้ถ้าต้องการ)
4. ระหว่างอัด **ต้องเปิดหน้านั้นค้างไว้** หน้าเว็บส่งวิดีโอเป็นชิ้นละ 3 วินาทีให้บอทเรื่อยๆ การ์ดใน Discord เปลี่ยนเป็น 🔴 กำลังอัด และ**บอทเริ่มอัดเสียงในห้องของคนแชร์ไปด้วยตั้งแต่ตอนนี้** (ถ้ายังไม่มีการอัดเสียงอื่นใน server อยู่)
5. หยุดเมื่อ: กด ⏹️ ในหน้าเว็บหรือใน Discord, เลิกแชร์จอ, ออกจากห้อง, ครบความยาวสูงสุด, ปิดหน้า/เน็ตหลุดเกิน 45 วินาที, หรือไฟล์ถึง `CAPTURE_MAX_MB`
6. บอทต่อชิ้นส่วนเป็นไฟล์เดียว (ไม่ encode ภาพใหม่) แล้วส่งผลในการ์ดเดิมพร้อมไฟล์เสียงที่คู่กัน ถ้าตั้ง Drive ไว้จะเป็นลิงก์ และ**หน้าเว็บจะเปิดวิดีโอบน Google Drive ให้เอง** (ถ้าอัปไม่ได้ หน้าเว็บจะบอกให้ดูผลใน Discord)

ข้อเสนอส่วนตัวจาก 🌐 อัดผ่านเบราว์เซอร์ หมดใน 5 นาทีและเปิดอัดได้ครั้งเดียว ถ้าไม่มีใครเปิดทันเวลา ข้อความลิงก์จะเปลี่ยนเป็น ⌛ ลิงก์หมดเวลาแล้ว และไม่มีอะไรขึ้นในห้อง ลิงก์บนการ์ดของ session ไม่หมดเวลาตามนั้น ใช้ได้ตลอดที่ยังอัดอยู่ (หรือถึงความยาวสูงสุดที่ตั้งไว้) แต่เปิดได้ครั้งเดียวเช่นกัน ลิงก์เป็นของคนแชร์คนเดียว อย่าส่งต่อให้คนอื่น เพราะคนที่เปิดก่อนจะได้อัดจอของคุณ

**ตั้งค่า (env):**

| ตัวแปร | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `PUBLIC_URL` | ว่าง | URL สาธารณะของบอท เช่น `https://recorder.example.com` (ไม่มี `/` ท้าย) **ว่าง = ปิดโหมดเบราว์เซอร์** และไม่เปิดหน้าอัดจอ ถ้าไม่ใช่ https (และไม่ใช่ localhost) บอทเตือนตอนเริ่ม เพราะเบราว์เซอร์อนุญาตอัดจอเฉพาะ https หรือ localhost |
| `HTTP_PORT` | `8080` เมื่อมี `PUBLIC_URL` | พอร์ตของ HTTP server ถ้าตั้งโดยไม่มี `PUBLIC_URL` จะเปิดแค่ `/healthz` (ไว้ให้ k8s probe) ที่เหลือตอบ 404 ถ้าไม่ตั้งทั้งคู่จะไม่เปิดพอร์ตเลย |
| `CAPTURE_MAX_MB` | `3072` | ขนาดรวมสูงสุดของวิดีโอต่อการอัด 1 ครั้ง ถึงแล้วการอัดจบพร้อมส่งเท่าที่ได้ |
| `CAPTURE_TOTAL_MB` | `8192` | พื้นที่รวมของชิ้นวิดีโอที่ค้างในเครื่องจากทุกการอัดจอ (กันดิสก์ pod เต็ม) ถึงแล้วการอัดที่กำลังส่งจะจบด้วย "พื้นที่เก็บไฟล์ของบอทเต็ม" |
| `DELETE_AFTER_UPLOAD` | `false` | `true` = ลบโฟลเดอร์ `recordings/<guild>-<เวลา>/` หลังอัปโหลด Drive สำเร็จ **ทุกไฟล์** ในโฟลเดอร์ และไม่มีการอัดอื่นใช้โฟลเดอร์นั้นอยู่ (ต้องตั้ง Drive ด้วย ไม่งั้นไม่ลบ) |
| `SCREEN_MODE` | `agent` (มี `PUBLIC_URL`) / `screen` | "อัดจอด้วย" เริ่มต้นของ server ที่ยังไม่ได้ตั้งค่า: `agent` หรือ `browser` (เลือกใน `/settings` ได้) |

บน Mac ที่เปิดทั้ง `screen`/`window` และ `browser` ได้พร้อมกัน เลือกโหมดต่อ server ใน `/settings`

**ทดสอบในเครื่อง:**

```
PUBLIC_URL=http://localhost:8080 npm start
```

`localhost` ใช้ได้เฉพาะ **เบราว์เซอร์บนเครื่องเดียวกับบอท** (เบราว์เซอร์ถือว่าปลอดภัยพอให้อัดจอ) ถ้าคนแชร์อยู่คนละเครื่อง ลิงก์ที่ชี้ `localhost` จะเปิดไม่ติด ให้เปิด tunnel เป็น https แล้วตั้ง `PUBLIC_URL` เป็น URL นั้น เช่น
`cloudflared tunnel --url http://localhost:8080` หรือ `ngrok http 8080` (ถ้า URL เปลี่ยนต้องตั้ง `PUBLIC_URL` แล้วรันบอทใหม่)

**Ingress / TLS บน k8s:** `k8s/deployment.yaml` มี Service (ClusterIP พอร์ต 80 → 8080) และ `k8s/ingress.yaml` เปิดสู่ภายนอกเฉพาะ `/capture`, `/static`, `/api/capture`, `/agent`, `/api/agent` (`/healthz ไม่ถูกเปิดออกนอก cluster)

1. แก้ `recorder.example.com` ใน `k8s/ingress.yaml` (ทั้ง `tls.hosts` และ `rules.host`) และ `PUBLIC_URL` ใน ConfigMap ให้เป็นโดเมนจริงตัวเดียวกัน
2. ต้องมี TLS: ใช้ cert-manager (เอา comment annotation `cert-manager.io/cluster-issuer` ออกและแก้ชื่อ issuer) หรือสร้าง secret `discord-recorder-tls` เอง **ถ้าไม่มี TLS จริง nginx จะใช้ใบรับรองปลอม เบราว์เซอร์จะขึ้นเตือนและหน้าอัดจอใช้ไม่ได้**
3. `kubectl apply -f k8s/deployment.yaml -f k8s/ingress.yaml`

หมายเหตุ:
- Ingress จำกัด 10 request/วินาทีต่อ IP (`limit-rps`) การอัด 1 หน้าใช้ไม่ถึง 1 ต่อวินาที แต่ถ้าหลายคนอยู่หลัง IP ออฟฟิศเดียวกันจะใช้โควตาร่วมกัน
- ลิงก์อัดจอ (`/capture/<token>`) จะติดอยู่ใน access log ของ nginx คนที่อ่าน log ได้จะเปิดลิงก์ก่อนเจ้าของได้ภายใน 10 นาที ถ้ากังวลให้จำกัดคนเข้าถึง log
- ถ้าคนแชร์เผลอปิดหรือรีเฟรชหน้าอัดจอ ช่วงนั้นจะจบ (ถ้ายังมีคนแชร์อยู่ session รอ 2 นาทีให้กด 🔴 ต่อ) คนที่ปิดต้องหยุดแชร์ใน Discord แล้วแชร์ใหม่ถึงจะได้ปุ่ม 🔴 อีกครั้ง

Ingress ตั้ง `proxy-body-size: 20m` และปิด `proxy-request-buffering` เพราะชิ้นส่วนวิดีโอใหญ่ได้ถึง 16MB ต่อชิ้น ถ้าใช้ ingress controller อื่นต้องตั้งให้เทียบเท่า
ไฟล์วิดีโอใช้ราว 0.9GB/ชม. ต่อคนที่อัด (และ ×2 ชั่วคราวตอนต่อไฟล์) `emptyDir` ใน manifest จึงตั้ง 20Gi (เผื่อไฟล์ที่รวมแล้วด้วย)

**เบราว์เซอร์ที่รองรับ:** Chrome, Edge, Firefox, Safari บน **คอมพิวเตอร์** (มือถือไม่รองรับการอัดจอ) ไฟล์ที่ได้เป็น mp4 (H.264) ถ้าเบราว์เซอร์อัดได้ ไม่งั้นเป็น webm (VP8/VP9) ซึ่งเปิดได้ในเบราว์เซอร์และ VLC แต่บางโปรแกรมไม่รองรับ

- **เสียงในวิดีโอ:** session ส่ง `meeting.mp4` (หรือ `.webm` ถ้าเป็นทางลัดจากเบราว์เซอร์ที่อัดเป็น webm) ไฟล์เดียว มีภาพทุกช่วงและเสียงห้องต่อเนื่อง ปุ่ม ▶️ ดูวิดีโอ เปิดไฟล์นี้ ถ้ารวมไม่สำเร็จจะส่งแยกไฟล์ (ไม่เกิน 3 วิดีโอ + `voice.mp3`) พร้อมหมายเหตุ การอัดแบบเดิม (กด 🖥️ บน Mac หรือลิงก์ส่วนตัว) ยังได้ `screen-with-audio.*` + 🎧 ฟังเสียง

**ถ้าคนแชร์เปิดลิงก์บนมือถือ:** หน้าเว็บบอกว่า `📱 อุปกรณ์นี้อัดจอไม่ได้ — เปิดลิงก์นี้จากคอมพิวเตอร์ หรือกด 🎙️ อัดเสียง ใน Discord ถ้าจะอัดแค่เสียง` บอทไม่อัดอะไรแทน ลิงก์ยังเปิดจากคอมพิวเตอร์ได้

**ข้อจำกัด:**

- คนแชร์ **ต้องกดเอง** บอทเริ่มอัดให้เองไม่ได้ เพราะ Discord ไม่ให้บอทรับภาพวิดีโอ และเบราว์เซอร์บังคับให้ผู้ใช้เลือกจอเอง ถ้าไม่มีใครกดลิงก์ จากการ์ด: บอทรอในห้องโดยไม่อัดอะไรจนการแชร์จบ แล้วจบเป็น ⚪ ไม่ได้อัด กดเอง: ข้อเสนอหมดใน 5 นาทีและไม่มีอะไรถูกอัด
- อัดได้ 1 session ต่อ 1 server (หลายช่วง หลายคนแชร์ต่อกันได้ ดูหัวข้อการ์ดด้านบน) และเป็นจอของคนที่ถูกกดเท่านั้น (หรือคนแชร์ที่มีตัวอัดในโหมดอัดอัตโนมัติ) คนถัดไปจะได้ปุ่มใหม่เมื่อการอัดก่อนหน้าจบ
- ปิดแท็บแล้วอัดต่อไม่ได้ (ได้เท่าที่ส่งมาแล้ว) ถ้าเน็ตสะดุด ชิ้นที่ขาดอาจทำให้วิดีโอมีช่วงหาย บอทจะบอกในผลลัพธ์
- ถ้าบอท restart ระหว่างอัด ลิงก์ทั้งหมดใช้ไม่ได้ และการอัดที่ค้างหยุดทันที (ดูหัวข้อ "เมื่อบอทรีสตาร์ท" ด้านบน)

## ข้อควรระวัง

- แจ้งทุกคนในห้องก่อนอัดเสียง
- `/screen` อัดจอเครื่องคุณจริง ใช้ `ALLOWED_USER_IDS` จำกัดคนที่สั่งได้
- อย่า commit `.env`
- ปิด **Public Bot** ใน Discord Developer Portal → Bot ไม่อย่างนั้นใครก็เชิญบอทไปอัดจอเครื่องคุณได้ (หรือตั้ง `ALLOWED_GUILD_IDS`)
- จอ Mac มีจอเดียว จึงอัดจอเครื่องได้ทีละ 1 server ถ้า server อื่นกำลังอัดอยู่จะเริ่มอัดไม่ได้ (การอัดผ่านเบราว์เซอร์ไม่นับ)

## ทดสอบ

```
npm test              # ทดสอบแบบออฟไลน์ ไม่ต้องล็อกอิน Discord ราว 10 วินาที
npm run test:browser  # ทดสอบหน้าอัดจอใน Chrome แบบ headless
```

- `npm test` ไม่ใช้ `.env` และไม่เชื่อม Discord จริง เทสที่รับชิ้นวิดีโอ (capture) ต้องใช้ `ffmpeg` บน PATH เพื่อสร้างไฟล์ตัวอย่างชั่วคราว ถ้าไม่มี ffmpeg เทสชุดนั้นจะถูกข้าม
- `npm run test:browser` ต้องมี Google Chrome ที่ `/Applications/Google Chrome.app` หรือระบุ path ด้วย `CHROME_PATH=...` ถ้าไม่พบ Chrome เทสจะถูกข้าม ไม่ถือว่าล้มเหลว

## รันบอทค้างไว้บน Mac (launchd)

ถ้าอยากให้บอทเริ่มเองหลังล็อกอิน และเปิดใหม่เองเมื่อหยุดทำงาน ใช้ launchd ได้ ไม่บังคับ

1. หา path ของ node ด้วย `which node` (เช่น `/opt/homebrew/bin/node`) แล้วแทนค่าใน `ProgramArguments`
2. สร้างไฟล์ `~/Library/LaunchAgents/com.example.discord-recorder.plist` (เปลี่ยน `com.example` เป็นชื่อของคุณเอง):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.example.discord-recorder</string>
    <key>ProgramArguments</key>
    <array>
        <string>/ABSOLUTE/PATH/TO/node</string>
        <string>/Users/rtliz/discord-recorder/src/index.js</string>
    </array>
    <key>WorkingDirectory</key>
    <string>/Users/rtliz/discord-recorder</string>
    <key>EnvironmentVariables</key>
    <dict>
        <key>PATH</key>
        <string>/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin</string>
    </dict>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/Users/rtliz/Library/Logs/discord-recorder.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/rtliz/Library/Logs/discord-recorder.log</string>
</dict>
</plist>
```

- `PATH` ใส่ไว้เพราะ launchd ไม่โหลด PATH จาก shell ถ้า `ffmpeg` อยู่ที่อื่นให้แก้ตรงนี้
- `WorkingDirectory` ต้องเป็นโฟลเดอร์ของบอท เพื่อให้อ่าน `.env` และสร้าง `recordings/` ถูกที่

```
launchctl load -w ~/Library/LaunchAgents/com.example.discord-recorder.plist     # เริ่มและเปิดเองทุกครั้งที่ล็อกอิน
launchctl unload -w ~/Library/LaunchAgents/com.example.discord-recorder.plist   # หยุดและไม่เปิดเองอีก
tail -f ~/Library/Logs/discord-recorder.log                                    # ดู log
```

- แก้ plist แล้วต้อง `unload` แล้ว `load` ใหม่
- อย่ารัน `npm start` พร้อมกับ launchd ในเครื่องเดียวกันหรือเครื่องอื่น บอทสองตัวจะตอบทุกคำสั่งสองครั้ง
- ถ้าใช้อัดจอเครื่องโหมด `screen`/`window` ต้องให้สิทธิ์ **Screen Recording** แก่ **node** (path เดียวกับ `ProgramArguments`) ที่ System Settings → Privacy & Security เพราะ launchd รัน node เอง ไม่ได้รันผ่าน Terminal
- การอัดที่กำลังทำอยู่จะหายถ้าบอทหยุดทำงาน (เช่น Mac รีบูต)

## Deploy บน Kubernetes

ใน pod ไม่มีจอ จึงตั้ง `SCREEN_ENABLED=false` (Dockerfile ตั้งไว้ให้แล้ว) ซึ่งปิดเฉพาะการอัดจอของเครื่องที่รันบอท (`screen`/`window`) ถ้าไม่ตั้ง `PUBLIC_URL` คำสั่ง `/screen`, `/settings`, `/agent` และการ์ดแชร์จอจะถูกปิดทั้งหมด เหลือ `/record` (อัดเสียงด้วยการกด) ถ้าตั้ง `PUBLIC_URL` จะอัดจอได้ผ่านตัวอัดหรือเบราว์เซอร์ของคนแชร์ ดูหัวข้อ "อัดจอผ่านเบราว์เซอร์"
`data/` (`settings.json` และ `agents.json` ซึ่งเก็บ hash ของ credential ตัวอัด) อยู่บน PVC `discord-recorder-data` 1Gi ใน `k8s/deployment.yaml` ถ้า cluster ไม่มี default storage class ให้เปิดบรรทัด `storageClassName` ไม่มี PVC = ทุกครั้งที่ pod restart ต้องตั้งค่าใหม่และจับคู่ตัวอัดใหม่ (ถ้าเปลี่ยนจาก emptyDir เดิม ค่าเก่าหายครั้งเดียว)
ถ้าต้องการอัดจอเครื่อง (ไม่ใช่จอของคนแชร์) ให้รันบอทแบบ local บนเครื่องที่มีจอแทน

```
docker build -t REGISTRY/discord-recorder:latest . && docker push REGISTRY/discord-recorder:latest
kubectl apply -f k8s/deployment.yaml          # แก้ image, GOOGLE_CLIENT_ID, PUBLIC_URL ก่อน
kubectl apply -f k8s/ingress.yaml             # ถ้าใช้อัดจอผ่านเบราว์เซอร์หรือตัวอัด (แก้ host ก่อน เปิด /agent และ /api/agent ด้วย)
cp k8s/secret.example.yaml k8s/secret.yaml    # กรอกค่าลับ (secret.yaml ห้าม commit)
kubectl apply -f k8s/secret.yaml
```

- มี readiness/liveness probe ที่ `/healthz` (พอร์ต `HTTP_PORT`)
- ตัวอัดที่ออนไลน์ถือ long-poll ค้างไว้เครื่องละ 1 connection (`HTTP_MAX_CONNECTIONS` ค่าเริ่มต้น 512) และ ingress ต้องมี timeout ≥ 60 วินาที (manifest ตั้ง 120) ไม่มี Node/ffmpeg ของตัวอัดอยู่ใน image
- `replicas: 1` + `Recreate` เพราะเป็น gateway bot รันซ้ำไม่ได้
- ไฟล์อัดเก็บใน `emptyDir` (หายเมื่อ pod restart) จึงควรตั้งค่า Google Drive ไว้ ไม่อย่างนั้นไฟล์เกิน 10MB จะไม่มีทางส่งออกมา (ตั้ง `DELETE_AFTER_UPLOAD=true` ได้ เพื่อลบไฟล์หลังอัปโหลดสำเร็จ กันดิสก์เต็ม)
- ไฟล์ PCM ดิบใช้ราว 11.5MB/นาที/คนที่พูด ปรับ `sizeLimit` ตามความยาวการประชุม
